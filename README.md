# Suara.space

**Suara.space** is a web-based music platform designed for discovering and listening to relaxing music.

The project was developed as a web development project with a focus on creating a simple and comfortable music-listening experience.

## Features

* Browse relaxing music
* Play and pause music
* Music navigation
* Music categorization
* Simple and responsive interface
* User-friendly music player

## Tech Stack

* HTML
* CSS
* JavaScript
* PHP

## Installation

### 1. Clone the repository

```bash
git clone https://github.com/IrsyadNabil/Suara.space.git
```

### 2. Move the project

If you are using XAMPP, place the project inside:

```text
htdocs/
```

### 3. Start the server

Start Apache from XAMPP and open:

```text
http://localhost/Suara.space
```
